The 33 objects, their models, and how much each one is handled

Every HOT3D recording puts a handful of these objects on a table. The release ships one rigid mesh per object and a motion-capture pose track for it in every annotated recording. This page shows the meshes themselves, what they measure, how often each appears, and how much each one actually moves.

Motion in the twelve featured recordings

Twelve Aria recordings are served here with their full per-frame payloads, and between them they cover all 33 objects. For each object below: how far its ground-truth position track runs, the same figure per minute of recording, the share of frames in which it has a pose at all, and the share in which the release also reports it as visible in the RGB image. Travel is summed frame to frame over consecutive annotated frames only: a gap in the pose track is left open, never crossed in one straight jump, so for a partly annotated object the figure is a lower bound. It also accumulates annotation noise, so an object that never leaves the table still reads a little above zero; treat small values as "stationary", not as an exact distance. Visible means the released per-frame visibility ratio for the RGB box is above zero — the release also emits a box for frames where the object is inside the image but fully occluded, and those do not count here. (The payload's own travel_m field joins consecutive annotated samples straight across gaps, which inflates partly annotated tracks, so it is not used.)
