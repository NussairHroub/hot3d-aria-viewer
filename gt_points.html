One clip per recording, start to finish, at real speed. The twenty points per object are read from HOT3D's ground-truth object map in every frame, so they are on the object by construction. Tiles stream a 960 px version; every caption links to the same recording at full 1920×1280. The preprocessing gallery shows the same objects over the manipulation window only, with the points tracked instead of read.

What you are looking at

These points have no correspondence between frames

Each frame's twenty points are spaced evenly around whatever outline the object has in that frame. The seventh point in one frame is not the seventh point in the next — it is only the seventh step around a new outline. They show where the object is, not where a tracker should have followed any particular spot to, so they cannot be triangulated the way tracked points can.

The outline is a silhouette, and silhouettes slide

A point on the outline sits where the surface turns away from the camera. Move the camera and that boundary moves across the object even when the object has not moved at all. This is a property of the geometry, not of any method, and it is the reason outline points are a harder thing to track than a textured patch in the middle of a face.

Two tiers, both hosted off this site

At 1920×1280 these 119 recordings come to about 34 GB, and GitHub Pages serves no site over 1 GB, so both tiers live in a Hugging Face dataset repository. Tiles stream the 960 px version because nine of them playing at native rate would need roughly 180 Mbps to browse; each caption links to that recording's native file, which is the render with no downscaling at all.

The object is often not in view

Each recording outlines the objects the preprocessing run selected, so the two galleries pair tile for tile — but that choice was made inside a short manipulation window, and over a whole recording the wearer looks away, walks around and handles other things. The caption gives the share of the recording in which the release says each object is visible; outside that share there is nothing to draw, and where the run picked something other than the object being handled, the points sit perfectly on an object nobody touches.

No hands here

The preprocessing clips draw hand landmarks alongside the object points. These do not: the release's hand annotations are a separate licence and a separate projection, and nothing on this page depends on them. The hands page covers them.

Gaps are the object leaving the frame

Where fewer than thirty of the object's pixels are visible there is no outline to draw and the frame carries no points. That is the annotation saying the object is out of view or occluded, not a failure to find it.
