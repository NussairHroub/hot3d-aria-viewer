What you are looking at

The window, not the recording

The pipeline picks one manipulation window per recording from the hand trajectories, and only that stretch is processed. A clip is therefore much shorter than its recording, and the wearer still looks around inside it — a window is chosen on when the hands are doing something, not on whether the object stays in view.

The coloured rings are the tracked object points

Twenty points are placed around the object's outline in a reference frame and tracked through the window; the pale dots on the hands are the hand landmarks. One ring colour per object, and some windows carry two objects.

The prompt under each object is the one its key was configured with

Each caption lists what the window tracks and, beside it, the text prompt the detector was configured with for that object slot. The two do not always agree: the mask stage numbers its slots by how much of each object is visible, while the config assigned prompts to those same slots in the recording's own object order, and the orderings differ. — of — tracked objects sit under a prompt that names something else; those are marked ≠. The masks themselves come from the ground-truth object maps rather than from the detector, so a mismatched prompt did not pick the wrong object here — but it would if the pipeline were re-run with the detector doing the finding.

The arm was not inpainted away in this run

The pipeline has a stage that segments the wearer's forearm out and paints over it, so the scene looks as a robot would see it. On HOT3D it had almost no effect: for 117 of the 119 windows the inpainted frame is byte-identical to the one before it, because the arm prompt found nothing to remove. These clips are the output as produced, arm included.

The frame is rectified and rolled upright

Aria's RGB camera is a 1408×1408 fisheye mounted rotated. The pipeline rectifies it to a 1920×1280 pinhole at 90° field of view and turns it upright, which is why these frames are landscape and straight while the raw video on the other pages is square and rotated.
