World coordinates · one metric frame

The whole recording as one 3D scene

Every annotation in a HOT3D recording lives in the same metric world frame: the semidense scene points, the headset's trajectory and camera, the pose of each object, and both wrists. This page draws that frame directly and plays it on the recording's own timeline, so the motion capture can be read as geometry rather than as columns of numbers. Z is up; the origin is the world frame the release ships.

Reading the scene honestly

A frame where a signal has no pose is drawn as nothing at all. Objects leave the table, hands leave the tracking volume, and the MPS trajectory has gaps at the very start and end of a recording; in all of those cases the array holds NaN, and this page hides the item rather than parking it at the origin. The coverage strip above is the same information as a picture: the gaps in it are the frames where the box, the sphere or the dashed line disappears.

What this page does not show

Finger joints: the hand file carries the wrist pose plus UmeTrack's 22 joint angles, but no 3D landmarks, so only wrists are drawn here — see the hands page for what that model does contain. MANO: its parameters are in the HOT3D release but are not republished in these files at all, because their use is gated by the SMPL-X/MANO licence, so nothing on this page is drawn from MANO. Eye gaze: it is released in the Central Pupil Frame and this payload does not carry the transform that would put a ray into the world, so no gaze ray is drawn; the gaze page plots the angles themselves. Object meshes: the boxes here use each model's measured size, while the models themselves are on the objects page. Images: the RGB and SLAM frames belong to the sequence viewer, not to this world view.
